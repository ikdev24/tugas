# Tugas

A simple web application to manage team tasks and projects using Express.js, MariaDB and Pico CSS.

## Requirements

- Node.js
- MariaDB server

## Setup

1. Install dependencies (requires internet access):
   ```bash
   npm install
   ```
   _Note: Installation may fail in environments without network access._

2. Configure the database connection through environment variables if needed:
   - `DB_HOST`
   - `DB_USER`
   - `DB_PASS`
   - `DB_NAME`

3. Run the application:
   ```bash
   npm start
   ```

The application listens on port `3000` by default.
